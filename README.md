# 📝 To-Do List Web Application

A simple and modern **To-Do List Web Application** designed to help users manage daily tasks efficiently.  
This application provides task tracking, progress calculation, and task status management with a clean and responsive user interface.

---

## 🚀 Features

- ✅ Add new tasks with due date
- 📊 Real-time task statistics:
  - Total Tasks
  - Completed Tasks
  - Pending Tasks
  - Progress Percentage
- 🔄 Mark task as Complete
- ✏️ Edit task
- 🗑️ Delete task
- 🔍 Filter tasks (All / Pending / Completed)
- 🎨 Modern dashboard-style UI
